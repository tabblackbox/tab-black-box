Tab Black Box: history and settings

Restore opens tabs in new windows and never closes your existing tabs. Logins, cookies, sessions, form contents, scroll position, page state, and back/forward history are not restored. Restored tabs load fresh from their URL.

History

Backup file

The backup file is saved to Downloads/TabBlackBox/tab-backup.json and is updated at most hourly, only when something changed, and after a mass close. It lives on this computer only. If you delete or move it, it is recreated on the next export, but nothing older than what is still in extension storage can be recovered. If Chrome is set to "Ask where to save each file", you may see a save prompt. Chrome may show a download indicator on each export.
